# 她的世界 · HER WORLD

一个面向**电脑浏览器**的互动叙事序章。一个被搁置、尚未完成的程序被你唤醒；你们一起认识雨、修改天气，为第一场雨命名，并在运行日志中发现被留下的记忆。

- 时长：约 5–10 分钟，12 个交互节点
- 结局：这里只是第一次相遇，之后的故事与最终结局尚未确定
- 原创 HTML / CSS / JavaScript / Canvas，无运行时依赖，无第三方资源、追踪器或分析服务
- 使用真实 DOM 交互与代码绘制的雨夜场景，不是把设计图铺成页面

## 当前版本

界面会显示 `PROLOGUE v0.2.1`，样式与脚本使用一致的版本化路径，便于确认更新。

## 开始

用本地 HTTP 服务打开此目录，或发布至 GitHub Pages 的仓库根目录。无需构建步骤。

```sh
python3 -m http.server 8765
```

打开 `http://localhost:8765`，点击「建立连接」。可选择自己的 DMXAPI Key，或明确选择离线试玩。

## AI 与离线模式

AI 模式由玩家本人在密码框中输入并提交 Key。浏览器直接向以下固定地址发送请求：

- API：`https://www.dmxapi.cn/v1/chat/completions`
- 模型：`glm-5.3-flash`
- 每次开场或回应一次请求；无自动重试
- `max_tokens: 2048`（含推理），`reasoning_effort: low`；等待上限 30 秒；响应体上限 64 KiB
- 接受最终普通文本、文本内容块与兼容 JSON 对白，隐藏推理内容；模型无权改变章节、选项、记忆存储规则或结局
- 本页每次连接最多 20 次请求，仅为使用提醒，**不是计费保障或防滥用安全边界**

如果请求、额度或回复解析出错，故事停在当前选择，显示明确错误。已知 HTTP 状态不会被可选的响应清理失败覆盖；浏览器未提供可读响应时，不猜测状态码或断言 Key 有误。粘贴完整请求头、Bearer 前缀或带引号的内容会被本地校验提示，而不是悄悄改写凭据。玩家可以手动重试，或明确切换到作者编写的离线文本。不会把离线文本冒充 AI 回应。

**自动化测试使用模拟请求；另在云浏览器完成了一次故意无效凭据的连接诊断，收到认证拒绝。从未使用真实 Key，未验证账户模型权限或实际生成。云浏览器的连接结果不代表用户本机网络与 CORS 状态。** 如果服务商不允许浏览器直连，静态页面无法解除这个限制，需要另行部署安全转发服务。

### Key 与隐私

- Key 仅保存在当前页面 JavaScript 闭包内存中，提交后立即清空输入框
- Key 不写入 localStorage、sessionStorage、IndexedDB、Cookie、网址、日志或存档
- 刷新、离开页面、断开连接与重新开始会清除 Key；恢复进度后须重新输入
- 请求禁止重定向，不携带 Cookie 或 Referrer，使用 `cache: no-store`
- 浏览器扩展和页面脚本仍可读取运行时信息；建议使用低额度专用 Key，并在服务商设置额度
- 近期对话与当前回应会发送给 DMXAPI；游戏选择和 AI 文本会保存在本地浏览器
- 角色的“记忆”是虚构叙事；角色选择不保存某条引用，不等于删除完整本机存档

不要把真实 Key 写入源码、测试、提交记录或聊天。仓库没有服务器，也不包含 Key。

## 操作

- 多个场景可自由输入最多 80 个字，选项提供可选提示；命名时最多 20 个字
- 「运行日志」由玩家主动打开，关键记忆发现需要先阅读日志
- 「记忆」查看留下的记录
- 她的对白逐条、逐字出现，标点处稍停；按空格或「显示本句」完成当前句
- 对白展示期间暂时锁定输入；完成的故事状态先保存，刷新恢复完整记录，不重复收费
- 日志逐行出现，记忆和世界变化在对应对白后逐渐呈现
- 页眉暂停按钮控制动态效果；遵循系统减少动态效果设置并立即显示完整文本
- 底部连接状态按钮可更换模式或断开
- 「重新开始」需要确认；普通刷新恢复进度，不保留 Key
- 支持键盘选择、可见焦点、选项后焦点移动、日志 Tab 键盘左右切换

测试不需要真实 Key，不发起外部 API 请求。DOM harness 覆盖交互状态，不替代真实浏览器像素和布局检查。详情见 `TESTING.md`。
